Getting started

Invite the bot with the required permissions. Place its role above roles it must moderate. Use /config help to explore commands and enable protections individually. Anti-nuke and raid alerts require staff review; the bot does not silently mass-ban members.

Security note: This public site is informational. Administrative configuration happens inside Discord using Manage Server permissions. OAuth web administration is not included in this starter.

Privacy: The bot stores configured IDs, warning records, security logs, and backup metadata locally on the Render persistent disk. Server owners are responsible for retention and disclosure policies.
